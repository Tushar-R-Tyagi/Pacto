# PACTO

**P**ressure → **A**im → **C**onstraint → **T**erminate → **O**utcome reflection

A minimalist desktop productivity timer that forces an honest review after every focused work session.

---

## How it works

1. **Decide** what you'll produce in the next bout
2. **Work** — the window disappears so you can focus
3. **Review** when the timer ends — Complete, Shift, or Discard

Every session is logged locally. No accounts, no cloud, no distractions.

---

## Features

- Configurable bout length (1–180 minutes)
- Outcome commitment before each timer starts
- Shift mechanic to carry unfinished outcomes forward
- Session history grouped by date with time ranges
- Start and end chimes
- Optional lo‑fi focus music (drop `.mp3` files next to the `.exe`)
- Theme switcher (Windows 10, Windows XP, Arcade)
- Single portable `.exe` — no install required
